<p>
I graduated in 2026 with an <strong>MSc in Applied Computer Science</strong> from the
<strong>Vrije Universiteit Brussel</strong>, where my thesis built a deep-learning emulator
of a physical urban-climate model: downscaling coarse ERA5 reanalysis into
<strong>100 m air-temperature maps</strong> for European cities, to capture the urban heat
island in seconds instead of hours of simulation.
</p>

### 🧠 Machine learning & AI

- **Deep learning (PyTorch)**: residual U-Nets for climate downscaling, EDSR super-resolution, CNNs, custom losses, mixed-precision training on GPU
- **Few-shot & metric learning**: Siamese networks with contrastive and triplet loss on MiniImageNet
- **Classical ML (scikit-learn)**: regression, random forests, gradient boosting, imbalanced classification (fraud detection), cross-validation and feature engineering
- **LLM & agent systems**: agentic pipelines with tool use, structured outputs, multi-agent orchestration (LangChain/LangGraph, Anthropic API), evaluation harnesses
- **Geospatial & remote sensing**: ERA5, Sentinel-2, CORINE land cover, xarray/rasterio pipelines
- **Evaluation & analysis**: RMSE/MAE/PSNR/SSIM, ablations, error maps, pandas + matplotlib reporting in Jupyter

### 🔭 What else I build

- **Systems & IoT**: Java data structures, C on Contiki-NG, CoAP over DTLS
